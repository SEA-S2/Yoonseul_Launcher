# 윤띵 기린월드 OBT 입출금 인식 테스트

정식 배포판을 변경하지 않는 테스트 브랜치입니다.

- 로그로 확인된 쿠키 입금/출금 및 상점 품목·수량·금액 인식
- 모두 판매 개별 항목과 합계 중복 집계 방지
- 꿀·도토리 및 아이템 수표 지급 메시지는 쿠키 잔액으로 기록하지 않음
- 일반 입출금의 출처는 임의 추정하지 않고 기타/출처 미확인으로 표시
- 0.3.1 이전 자동 감지 기본 꺼짐 설정은 첫 업그레이드 시 한 번 켜짐으로 이전
- 이후 사용자가 다시 끄면 재실행해도 유지
- 자동 감지 채팅 구독은 설정을 실시간 확인
- 기존 영수증 디자인, 기록·내보내기 유지

게임을 종료하고 기존 윤띵 JAR을 mods 밖으로 옮긴 뒤 테스트 JAR 하나만 넣으세요. 과거 로그를 자동으로 소급 기록하지 않으며 적용 후의 새 거래를 확인하세요. 설정과 장부 폴더는 지우지 마세요.

확인할 항목: 새 쿠키 입금 1건, 상점 구매 1건, 모두 판매 1회(개별 합계가 한 번만 반영되는지). 송금·플리마켓 등 이번 로그로 확인되지 않은 문구는 후속 검증이 필요합니다.
