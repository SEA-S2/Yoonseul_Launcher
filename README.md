# 윤슬런처

Minecraft 26.2 Fabric 기반 윤슬런처와 윤슬 클라이언트 모드 소스입니다.

## 선택 장부 모드 안내

쿠키 수입·지출 장부는 기존 제작자 아카님의 **낙인(Nakin)**을 사용합니다.
낙인은 윤슬 런처와 별도 프로그램이며, 런처 기본 구성에 포함되거나 자동 설치되지 않습니다.
필요한 마을원만 마을 내부 설치 안내에 따라 별도로 설치해 주세요.

기존 윤띵 사용자는 게임을 종료하고 윤띵 JAR을 제거한 뒤 낙인으로 교체해 주세요.
기존 장부 기록은 필요하면 교체 전에 내보내거나 백업해 주세요.

## 기린월드 코어

- 오른쪽 Shift로 클라이언트 허브 열기
- 동글랜드 비공개 Java Agent 코드를 포함하지 않는 독립 구현
- Fabric API 기반 공개 소스

GitHub Actions의 **Build Yoonseul Mods** 작업에서 JAR을 빌드할 수 있습니다.
